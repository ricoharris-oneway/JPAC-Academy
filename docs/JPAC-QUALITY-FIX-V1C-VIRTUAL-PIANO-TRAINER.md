# JPAC Quality Fix v1C: Virtual Piano Trainer Foundation

This frontend-only update adds reliable multi-note highlighting, per-MIDI-note synthesized voices, and a local beginner trainer exercise. It does not record, upload, persist audio, or change academic systems.

The local samples were audited but excluded. Piano contains 12 WAV preset-style files (23,835,084 bytes), without note-name mappings. Guitar contains 6 WAV files (14,087,680 bytes) named `motif gtr 1` through `motif gtr 6`, indicating motifs rather than single-note mappings. Keep synthesis until assets are renamed, normalized, web-compressed, mapped in a manifest, and separately approved.
